# JSON Schema Draft 2020-12 definitions

These standard meta-schemas are copied without content changes from
`jsonschema-specifications` 2025.9.1, distributed under the included MIT license.
Vocabulary files have a `.json` suffix here for Go embedding.

Upstream: https://github.com/python-jsonschema/jsonschema-specifications
Standard: https://json-schema.org/draft/2020-12/schema

The Go validator uses these local resources to validate tool schemas without
network access. Schema loaders cannot read files or fetch URLs.
