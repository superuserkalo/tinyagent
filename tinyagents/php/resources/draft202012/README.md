# Draft 2020-12 schema definitions

These unmodified JSON files come from https://json-schema.org/draft/2020-12/schema
and its seven referenced meta-schemas. They let Opis check tool schemas locally
before compiling them. Runtime argument schemas cannot fetch external references.

Retrieved 2026-09-09. Each file retains its canonical `$id`. The JSON Schema
Specification Authors offer BSD-3-Clause or AFL-3.0; this distribution uses the
BSD-3-Clause option. The upstream license is included in `LICENSE`.
